# VALTERN — персональный сайт Daniel Valtern

Премиальный персональный сайт бренда VALTERN.

## Содержание

- Главная
- Обо мне
- Проекты и страница IdeaNest
- Мышление (заметки + поиск и теги)
- Путь (интерактивная шкала)
- Ремесло
- Контакт (проверка сообщения без ложной отправки)
- 404
- Тёмная / светлая тема

## Как открыть

Откройте `index.html` в браузере или залейте папку на любой статический хостинг.

## Как править тексты

Редактируйте HTML-файлы напрямую. Общие стили — `styles.css`. Поведение меню, темы, фильтров — `site.js`.

## Публикация

### GitHub Pages

1. Создайте репозиторий.
2. Загрузите содержимое этой папки в корень.
3. Settings → Pages → Deploy from branch → `main` / root.

### Cloudflare Pages

1. Подключите репозиторий.
2. Build command: оставьте пустым.
3. Output directory: `/` (корень репозитория).

### Свой домен

Подключается в панели GitHub Pages или Cloudflare Pages.

## Важно

- Telegram, GitHub и почта не опубликованы — форма не имитирует отправку.
- Лицо, адрес, школа, телефон, семья не публикуются.
- IdeaNest: продукт открыт, аудитории нет — статус честный.
