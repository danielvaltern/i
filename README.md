# Daniel Valtern / VALTERN — личный сайт

Готовый двуязычный статический сайт, адаптированный по структуре и визуальному языку из исходного сайта Rotarempy. Без сборщиков, Node.js, сторонних библиотек и внешних шрифтов.

## Что реализовано

- `index.html` — русская версия, `en.html` — английская.
- Светлая/тёмная тема, сохраняется в браузере.
- Выдвижная навигация слева, адаптирована для мобильных устройств.
- Биография, IdeaNest, интерактивная хронология и интересы.
- Метатеги SEO, schema.org, Open Graph, favicon, текстовый профиль, `robots.txt`, `llms.txt`.
- Адаптивный интерфейс, клавиатурная навигация, учёт `prefers-reduced-motion`.

## Локальный запуск

Можно открыть `index.html` в браузере. Для полноценной проверки по HTTP из папки сайта:

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080/`.

## Публикация на nginx + VPS

1. Распаковать **содержимое** папки на сервер, например в `/var/www/valtern`.
2. Настроить отдельный `server_name` на личный домен Daniel. Пример конфигурации:

```nginx
server {
    listen 80;
    server_name YOUR-DOMAIN.EXAMPLE;
    root /var/www/valtern;
    index index.html;
    location / { try_files $uri $uri/ =404; }
}
```

3. Настроить DNS-домен на IP VPS, включить HTTPS через сертификат и обновить конфигурацию nginx.
4. Когда домен известен, добавить абсолютные адреса для `canonical`, `og:image`, `hreflang` и создать `sitemap.xml`, чтобы поисковые системы не путали относительные URL. **Не использовать чужой домен Rotarempy.**

Можно также разместить сайт на GitHub Pages или Cloudflare Pages — достаточно папки сайта.
